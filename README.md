# MealDiary

A high-performance, "zero-hurdle" meal and bowel movement logging application with smart heuristic analysis, weight tracking, and personalized reminders.

## 🚀 Key Features

*   **Zero-Hurdle Logging:** Log meals and bowel movements with minimal taps.
*   **Recurring Suggestions:** Smart autocomplete for meals you log frequently.
*   **Extensive Health Tracking:** Track consistency (Bristol scale), pain, and duration for bowel movements.
*   **Heuristic Analysis (C++ Native):** High-performance pattern matching to identify food accelerators and decelerators.
*   **Advanced Statistics:** Visualize weight trends, BM frequency, and top foods.
*   **Modular Dashboard:** Swipeable, customizable in-app widget dashboard.
*   **Data Portability:** Export your entire history to CSV at any time.

## 🛠 Tech Stack

*   **UI:** Jetpack Compose (Material 3)
*   **Architecture:** MVVM, Clean Architecture
*   **Persistence:** Room (SQL), DataStore (Preferences)
*   **Background Tasks:** WorkManager
*   **Performance:** C++ JNI (CMake) for heuristic analysis
*   **Testing:** Robolectric (JVM-based UI testing) for speed
