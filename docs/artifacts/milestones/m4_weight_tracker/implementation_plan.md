# Milestone 4: Weight Tracker & Suggestion Engine Implementation Plan

## Objective
Introduce weight tracking and a smart suggestion engine that triggers after 7 days of use.

## Tasks
1. Update DataStore preferences for weight tracking.
2. Integrate Weight entries into the unified history feed.
3. Implement logic to suggest weight tracking after 7 days of first meal log.
4. Add Weight Logging UI to the main screen (when enabled).
5. Update Settings to allow manual weight tracking toggle.

## Verification
- Suggestion card appears after 7 days.
- Weight entries are persisted and displayed correctly.
- Weight tracking can be toggled in settings.
