# Milestone 1: Core Infrastructure Implementation Plan

## Objective
Establish the technical foundation for MealDiary, including Jetpack Compose, Room, and Native C++ support.

## Tasks
1. Initialize Jetpack Compose and Material 3.
2. Setup Room Database with `Meal`, `BowelMovement`, and `WeightEntry` entities.
3. Configure CMake and JNI for native C++ development.
4. Implement the "Zero Hurdle" logging UI (Main Screen).
5. Add unit tests for Room entities and baseline UI tests.

## Verification
- Project builds successfully.
- Room entities can be persisted and retrieved.
- UI allows basic meal logging.
- Tests pass.
